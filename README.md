# Security Monitoring & Incident Investigation Lab

## Overview

This project aims to build a practical cybersecurity monitoring environment using Wazuh, Sysmon and Windows Event Logs.

The objective is to understand how security events are collected, monitored, detected and investigated in a controlled laboratory environment.

## Objectives

- Deploy a SIEM monitoring environment.
- Collect and analyse Windows security events.
- Monitor endpoint activity using Sysmon.
- Configure and test security detection rules.
- Investigate simulated security incidents.
- Document findings and recommend remediation actions.

## Technologies

- Wazuh
- Ubuntu Server
- Windows 11
- Sysmon
- VMWARE
- Windows Event Viewer
- Git and GitHub
